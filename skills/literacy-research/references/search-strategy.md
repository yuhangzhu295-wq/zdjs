# Literacy Research Search Strategy

## 流程

```
识别关键词
  → SWITCH_TAB(对应数据库)
  → 站内检索 或 分类导航
  → 定位课程/知识点/工具说明
  → 打开正文并阅读
  → 提取 Evidence
```

## 检索策略

1. 优先站内搜索框输入关键词。
2. 无搜索框 → 用分类导航（课程 → 章节 → 知识点）。
3. 关键词无结果 → 换同义词/上位词（如「布尔逻辑」→「逻辑检索」）。
4. 找到候选条目 → 打开正文确认，不只看列表标题。

## 降级顺序（重要）

赛事指定数据库有明确答案 → 优先赛事数据库。
找不到 → 产品官网 → 官方Web → 普通Web。
**不要优先搜索博客。**

## Evidence 约定

- evidence_type = PRIMARY_DATABASE（赛事数据库）或对应来源类型（降级后）。
- 来源标注具体数据库名称。
